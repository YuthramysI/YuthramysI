### Featured projects

**🧪 [Rick and Morty Explorer](https://github.com/YuthramysI/RickyandMorty)** · [live](https://rickyandmorty-rust.vercel.app)
Next.js 16 + TypeScript app where a Gemini assistant answers by calling the live Rick and Morty API through 4 tools. NDJSON streaming, retries with exponential backoff, Zod validation, rate limiting, nonce-based CSP, Vitest + Playwright + axe accessibility checks, CI on every push.

**🏛️ Campus Navigator IUB** · [live](https://campusnavigatoriub.online)
3D campus model and guided 360° walking routes for Instituto Universitario de Barranquilla, with IUBot (local intent matching + Gemini). React 19, Three.js / React Three Fiber, Draco-compressed model, LRU texture cache, Fuse.js search, keyboard accessible.

**🌙 Lua Tech website** · [live](https://luatech.agency)
Trilingual (ES/EN/FR) scroll-driven site: Next.js 16 static export, custom GLSL shader hero in React Three Fiber, GSAP ScrollTrigger + Lenis, served from Cloudflare.

**🤖 Portfolio with AI agent lab** · [live](https://heyyuthramys.codes)
WebGL2 portfolio with an agent-orchestration interface: an orchestrator delegates tasks to research, analyst, developer and automation agents with typed tool calls and a visible execution trace.

**Client work (private code):** Gemini AI agent connected to the WhatsApp and Messenger APIs with CRM and admin dashboard · multivendor e-commerce and ERP system · WhatsApp Business + n8n automations for small businesses · BodySlender clinic site with local SEO.
